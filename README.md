# 書き取り帳

読めるのに書けない漢字を、文中の空欄に指で書いて練習する個人用アプリ。
電波がなくても動きます（一度ネットありで開いたあと）。

## インストール（Android）
1. Chrome で GitHub Pages のURLを開く
2. 右上「︙」→「ホーム画面に追加」（または「アプリをインストール」）

学習記録はスマホのブラウザ内にだけ保存されます。

## 自動判定のしくみ
書き順データ（KanjiVG）のお手本と、手書きを1画ずつ比べます（書き順は問いません）。
字全体の大きさ・位置・右上がりの傾きをそろえたあと、偏や旁などの部品ごとにも位置と大きさをそろえ直してから、
各画を一番近いお手本の画に割り当てます。続け書きした2〜3画も1画として扱えます。
- 朱色：お手本にあって手書きにない画（抜け）
- 黄土色：手書きにあってお手本にない画（余分）
- 青：対応はついたが形や位置がずれている画

ハネ・トメ・ハライや、線の長さだけが違う字（未と末など）は判定できません。判定は目安で、○△× は自分で選び直せます。
判定がおかしいときは「データをコピー」で書いた線をコピーできます。

## 書き順データ
`strokes.js` は KanjiVG（https://kanjivg.tagaini.net, Ulrich Apel, CC BY-SA 3.0）から
`tools/build_strokes.py` で出題語の字だけを取り出して作っています。出題語を増やしたらこのスクリプトを実行し直します。
